## Frontend rules

- Use modern SaaS-style UI
- Use TailwindCSS only
- Prefer clean spacing and visual hierarchy
- Avoid bootstrap-like design
- Use rounded-2xl cards
- Use subtle shadows
- Use responsive layouts
- Prefer glassmorphism only minimally
- Focus on UX clarity
- Keep animations subtle
- Use reusable components
- Never break existing functionality
